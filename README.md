# 商品上架表体检器

一个免费的商品 CSV 上架前检查工具，帮助小商家、运营助理和商品资料整理人员提前发现常见表格问题。

## 能检查什么

- 空标题
- 空 SKU/货号
- 重复 SKU/货号
- 空图片
- 异常价格
- 非整数库存
- 标题过长
- SEO 标题/描述过长或为空
- 疑似风险词
- 描述里的异常 HTML

## 隐私和安全

这个工具是纯前端静态页面。CSV 文件只在你的浏览器本地解析，不上传服务器，不需要登录平台，也不会自动上架。

## 使用方式

1. 打开网页。
2. 点击“载入示例”查看效果，或选择自己的 CSV 文件。
3. 查看严重、提醒、建议三类问题。
4. 下载体检报告。

## 支持边界

本工具只做格式、完整性和常见风险提示，不替代平台官方审核，不承诺导入成功、审核通过、搜索排名或成交结果。

## 人工服务

如果已经生成报告，但不知道怎么修，可以使用人工诊断或修表服务：

- 99 元：50 行以内人工诊断，只给问题清单和修复优先级。
- 299 元：100 行以内按客户模板修表，含一次复查。
- 699 元：100-300 行商品资料整理，含标题、卖点、SEO 字段、图片 ALT 基础整理。

付费前会先确认商品资料来源合规，不承接无授权搬运、刷量、规避风控、侵权品牌等需求。

发送表格前请先查看 [脱敏说明](./SANITIZE.md)。
